# Курсовой проект — «Накопления на лето»

Автор: Сиддикова А. М.  
Группа: 251-321

## Тема
Полноценный сайт на backend MVC-шаблоне на тему летних накоплений.
Цель проекта — показать, сколько нужно откладывать в июне, июле и августе, чтобы к концу лета накопить **67 000 ₽**.

## Что реализовано
- MVC-структура проекта;
- backend-маршрутизация;
- три тематических раздела по месяцам;
- калькулятор накоплений с расчётом по введённым параметрам;
- динамическое обновление результатов на JavaScript;
- раздел администрирования (CRUD);
- хранение данных в JSON-модели.

## Запуск
Из папки `course-work`:

```bash
php -S localhost:8000 -t www
```

или через XAMPP / OpenServer, открыв папку `www` как корень сайта.
