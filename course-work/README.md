# Курсовая работа — серверная веб-разработка

**Студент:** Сиддикова А. М.  
**Группа:** 251-321  
**Тема:** мини-приложение «Кулинарная книга»

Проект оформлен отдельной папкой `course-work` и запускается вместе с общим сервером лабораторных работ.

## Как открыть

Из корня всего проекта:

```bash
php -S localhost:8000
```

Потом открыть:

```text
http://localhost:8000/course-work/www/
```

## Что внутри

- список рецептов;
- просмотр отдельного рецепта;
- калькулятор калорийности по количеству порций;
- админ-раздел для добавления, редактирования и удаления рецептов;
- хранение данных в `data/recipes.json`, чтобы проект открывался без настройки MySQL;
- `schema.sql` оставлен как SQL-версия структуры базы данных.
