# Основы серверной веб-разработки

**Студент:** Сиддикова А. М.  
**Группа:** 251-321

Проект собран как единый сервер с отдельными папками лабораторных работ.

## Структура

- `index.php` — общее меню работ;
- `assets/theme.css` — стиль только для главного меню;
- `lab01`–`lab10` — отдельные лабораторные работы;
- внутри каждой лабораторной есть собственный `styles.css`, чтобы работа могла открываться отдельно и не зависела от общего оформления меню.

## Запуск

```bash
php -S localhost:8000
```

После запуска открыть:

```text
http://localhost:8000
```

## Проверка отдельных работ

Примеры адресов:

```text
http://localhost:8000/lab01/
http://localhost:8000/lab02/
http://localhost:8000/lab04/
http://localhost:8000/lab07/
```


## Курсовая работа

Курсовая находится в папке `course-work`. Открытие при запуске из корня проекта:

```text
http://localhost:8000/course-work/www/
```

Внутри есть `README.md`, `schema.sql`, MVC-структура, шаблоны, стили и пояснительная записка `.odt`.


Обновление: все лабораторные работы, главное меню и курсовая оформлены в едином pastel-стиле.
